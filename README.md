# projetCdaJusteUnPlat
## Installation

1. Cloner le projet :
git clone 

2. Aller dans le dossier backend :
cd backend

3. Installer les dépendances :
npm install

4. Créer un fichier .env à la racine :
MONGO_URI=mongodb://localhost:27017/bddRecettes
JWT_SECRET=
PORT=3000

## Lancer le serveur

- Mode normal :
npm start

- Mode développement (nodemon) :
npm run dev
